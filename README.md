
# 🍦 Ice Cream Management System

A **Java console application** to manage **Ice Creams**, their **types**, **companies**, and **prices**.
Supports adding ice creams, finding the most expensive one, sorting by price, and searching by company.

---

## ✨ Features

### 🍨 Ice Cream Management

* Add new ice creams ✅
* Check for duplicates ⚠️
* Print all ice creams 📜
* Find the **most expensive** ice cream 💰
* Sort ice creams by price 🔝
* Search ice creams by company 🔍

---

## 📂 Structure

```
IceCreamProject/
├── IceCream.java   # Class representing an Ice Cream
└── Main.java       # Main program with menu-driven operations
```

**Class Relationships:**

* **IceCream** → type, company, price
* **Main** → manages a list of IceCream objects and operations

---

## 🚀 How to Run

1. Compile:

```bash
javac IceCreamProject/*.java
```

2. Run:

```bash
java IceCreamProject.Main
```

3. Follow console prompts to add, view, and manage ice creams.

---

## 💡 Notes

* Duplicate ice creams are **not allowed**
* Automatically finds **highest priced ice cream**
* Simple console-based **menu interface**
